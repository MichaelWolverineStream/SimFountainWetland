<initial idea>
I want to build a simple simulation app and I wonder what tech to use. The app is a simple simulation game where the user configures a "fountain" placed in a wetland. The goal is to aerate the wetland water with the smallest effort possible (size of the fountain and energy used by the fountain).

A simulation session should start with creating a new terrain. The user should be able to add an aerial photograph of a landscape, color in a continuous area that is wetland, and then the game generates the terrain for the simulation. The generated terrain is a 3d volume of a specific depth (user adjustable) based on the initial photo coloring.

Step two is that a baseline oxygen distribution within the wetland is simulated without a fountain using certain configurable settings like season of the year, rainfall and wind. The oxygen distribution can be visualized as a 3d plot throughout the body of water, as well as total dissolved oxygen.

Step three is that a "fountain" can be placed, which consists of two parts: a pump (inlet) and a sprayer (outlet). The user places the pump somewhere on the bottom, and the sprayer somewhere on the surface. The user can configure throughput (liters per minute).

</initial idea>
